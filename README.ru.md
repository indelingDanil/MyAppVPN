## Что это

MyAppVPN — клиент Xray / VLESS для Android. Нажимаете одну кнопку — приложение само находит рабочий сервер, подключается и на лету переключается на другой, если текущий заблокировали. Серверы берутся из открытых списков и из собственной автообновляемой подписки [MyAppVPN-subs](https://github.com/indelingDanil/MyAppVPN-subs). Если обычные серверы не проходят (например, на мобильном интернете с «белыми списками»), есть режим **OpenFlux** — свой выход на обычном веб-хостинге.

Личный проект с открытым кодом: не стартап, без инвесторов и без телеметрии. Уже более 30 000 скачиваний.

## Возможности

- **Авто-режим** — одна кнопка: приложение само находит рабочий сервер и подключается.
- **Встроенный балансировщик** — проверяет серверы по **реальной доступности Telegram** (а не просто пингом) и держит самый быстрый рабочий.
- **Бесшовное переключение** — если сервер заблокировали, трафик уходит через другой без переподключения.
- Переключатель **Авто / Вручную** — можно выбрать сервер самому, переключение на лету.
- **Фильтр стран** — российские серверы исключены по умолчанию (задержка низкая, но Telegram/YouTube оттуда не работают); настраивается.
- Список серверов обновляется сам в фоне (zieng2/wl, igareck, MyAppVPN-subs).
- **Раздельное туннелирование** — выбираете приложения, которые идут мимо VPN, или обратный режим «Только выбранные через VPN».
- **Свои DNS** — Cloudflare, Google, Quad9, AdGuard, Яндекс или любой свой (DoH / обычный), запросы идут через туннель.
- **Обход DPI (фрагментация TLS)** — отдельная настройка, по умолчанию выключена.
- **OpenFlux (Beta)** — свой выход на обычном веб-хостинге, ссылки `openflux://`, диагностика подключения.
- **Раздача через точку доступа** — HTTP-прокси и SOCKS5 с паролем, с пошаговой инструкцией.
- **Kill switch**, **Always-on VPN** и автоподключение при загрузке телефона; свои подписки — в Настройки → Подписки.
- Статистика трафика в реальном времени, «стеклянный» дизайн, **светлая и тёмная темы**, интерфейс на русском и английском (по языку системы).

## Быстрый старт

1. Скачайте и установите APK.
2. Откройте приложение и нажмите **ПОДКЛЮЧИТЬ**.
3. Дождитесь «Поиск рабочего сервера…» → «Защищено». Готово.

Чтобы выбрать сервер вручную — переключатель **⚡ Авто | 📍 Вручную** на главном экране или вкладка **Серверы**.

## OpenFlux

OpenFlux (Beta) — для сетей, где обычные VLESS-серверы блокируются: приложение пускает трафик через **ваш собственный выход на обычном веб-хостинге**, а сессии переживают обрывы связи. К любой ноде OpenFlux можно подключиться и по ссылке `openflux://`. Инструкция по настройке — в ветке [`openflux-exit`](https://github.com/indelingDanil/MyAppVPN/tree/openflux-exit).

## Своя подписка: MyAppVPN-subs

[MyAppVPN-subs](https://github.com/indelingDanil/MyAppVPN-subs) — бот на GitHub Actions: сам находит публичные VLESS-подписки, выкидывает удалённые и заброшенные источники, раз в 3 часа собирает и проверяет серверы, оставляет только REALITY / TLS и публикует очищенный список с флагами стран. В приложение он встроен как «MyAppVPN (авто-сбор)» (отключается в Настройки → Подписки). Ссылка для других клиентов (v2rayNG, Hiddify и т.п.):

```
https://cdn.jsdelivr.net/gh/indelingDanil/MyAppVPN-subs@output/vless.txt
```

Зеркала, списки по странам и статистика — в [README репозитория](https://github.com/indelingDanil/MyAppVPN-subs#readme).

## Вопросы и ответы

**При установке пишет «Приложение не установлено».**
У вас 32-битный Android — скачайте APK `arm32`.

**Подключается, но сайты не открываются.**
Выберите другой сервер в ручном режиме или вернитесь в Авто. Не помогло — включите **«Обход DPI (фрагментация TLS)»** в Настройки → Подключение.

**Мобильный интернет пускает только на сайты из «белого списка».**
В таких сетях обычные серверы часто не работают. Используйте OpenFlux со своим выходом; кнопка **«Диагностика подключения»** на экране OpenFlux покажет, какие сервисы доступны и похоже ли это на режим «белых списков».

**Это безопасно?**
В приложении нет телеметрии, код открыт. Но бесплатные публичные серверы держат неизвестные люди — не передавайте через них ничего ценного.

**Как пустить банковское приложение мимо VPN?**
Настройки → Выбор приложений → отметьте нужные. Или включите режим «Только выбранные через VPN» и отметьте те, что должны идти через туннель.

**Будет ли версия для iOS?**
Пока нет. Донаты идут на Mac — если накоплю, попробую сделать версию и для iPhone.
