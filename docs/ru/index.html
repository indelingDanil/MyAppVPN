Что умеет

Сделан для сетей, где режут

Режим «Авто»

Одна кнопка. Приложение проверяет серверы и подключается к самому быстрому из тех, через которые реально открывается Telegram, а не просто с лучшим пингом.

Переключение без разрыва

Если сервер заблокировали, трафик на лету уходит на другой — соединение не рвётся.

Бесплатные серверы внутри

Встроенная подписка, которую бот собирает и проверяет каждые несколько часов. Можно добавить и свои подписки.

VLESS + REALITY

Работает на Xray-core. Во встроенный список попадают только серверы с REALITY и TLS.

Раздельное туннелирование

Выберите приложения, которые идут мимо VPN, — или наоборот, пускайте через VPN только выбранные.

Обход DPI

Фрагментация TLS по желанию: начало соединения дробится, и простой DPI не может прочитать имя сервера.

OpenFlux

Свой выход на обычном веб-хостинге — для сетей, где обычные серверы не проходят. Бета.

Телефоны и ТВ

Работает на приставках и телевизорах с Android TV, раздаёт VPN через точку доступа, есть kill switch и постоянный VPN.

Вопросы

Что обычно спрашивают

MyAppVPN бесплатный?

Да. Без подписки, рекламы и аккаунта. Это личный проект с открытым кодом; донаты приветствуются, но не обязательны.

Какой файл скачивать?

arm64 подходит для большинства телефонов, приставок и телевизоров. Если пишет «Приложение не установлено» — берите arm32: он для 32-битных и старых бюджетных устройств. Нужен Android 8.0 или новее.

Почему его нет в Google Play?

У Google Play строгие правила для VPN-приложений, а приложение работает с публичными серверами, которыми не владеет. Официальный источник — APK на GitHub Releases; обновления ставятся поверх и сохраняют настройки.

Бесплатные серверы безопасны?

Это публичные серверы неизвестных людей. Незашифрованный трафик им виден, поэтому не передавайте через них пароли и банковские данные. HTTPS-сайты остаются зашифрованными. Для важного добавьте свой сервер или подписку.

Какие протоколы поддерживаются?

VLESS с REALITY или TLS поверх TCP, WebSocket, gRPC, HTTPUpgrade, XHTTP и mKCP — через Xray-core. Плюс OpenFlux — отдельный режим со своим выходом на веб-хостинге.

Приложение собирает данные?

Нет: ни телеметрии, ни аналитики. Код открыт под GPL-3.0 — проверить может любой.

Работает на Android TV?

Да, на приставках и телевизорах с Android 8.0+. Ставьте APK arm64 — его поддерживает большинство приставок.
